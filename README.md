# draggy.org

This repo is the website for Draggy, the free and open source desktop app that runs models on your own computer. The app itself lives in [Lucki74/draggy](https://github.com/Lucki74/draggy).

It is published at https://draggy.org in English, French, Spanish and Russian.

## Run it

```bash
npm ci
npm run build
npm test
```

Serve `public/` on any static server, for example `python -m http.server 4173 -d public`.
