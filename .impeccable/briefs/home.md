# Surface brief: Home (and the shared shell)

Mode: Persuade. Download and Wiki shell share the world; the wiki is Read.

- THESIS: a desktop assistant that lives on your own machine, shown as a warm light burning in
  a dark workshop. The app window is the hero; the page is the room around it.
- OWN-WORLD: "night workshop". Near-black canvas with a faint blue cast, one ember-orange light
  source glowing behind the app window, fine grain. Light theme: warm paper, darker ember.
  References: Linear and Raycast for the dark canvas and precision, Apple and Framer for the
  scale and pacing of the hero, Zed for the honest, code-literate detail.
- STORY: what it is (hero) -> what it will not do to you (promises) -> what it does (Chat and
  Code, Talk, extensions) -> your models, local or a provider (2.2) -> first launch (2.2) ->
  what it needs -> download.
- FIRST VIEWPORT: heading, one-line lede, OS-detected download button, source link with the
  GitHub star count, and the app window with Chat, Code, Talk tabs, glowing ember behind it.
- FORM: sticky translucent nav; large display type in Mona Sans (variable), Geist Mono only
  for code and measurements; hairline borders, 12 to 20px radii, soft layered shadows. No
  eyebrows, no hard offset shadows, no same-size card grids as structure.
- FINISH: themed selection, focus rings, scrollbars, caret in ember; tabular numerals in
  specs; reduced motion removes all movement.
